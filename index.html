Why Developers Choose PortGrid

Unlike brittle docker-compose files and heavy VMs, PortGrid treats your workstation as an isolated, cryptographically auditable local cloud.

Deterministic Port Allocation

Never see "address already in use" again. PortGrid probes sockets before binding and deterministically increments ports without breaking connection strings.

Strict 127.0.0.1 Enclaves

Containers bind strictly to local loopback sockets. Zero external network exposure, eliminating accidental exposure over LAN, Wi-Fi, or public cloud bridges.

FIPS 140-2 Entropy Secrets

Generates high-entropy AES-256-GCM passwords per instance. Secrets are sealed into an encrypted local vault and formatted into ready-to-copy .env files.

SHA-256 Merkle Audit Trail

Every container spawn, credential generation, or volume purge writes an immutable cryptographic block to a tamper-evident audit chain with verifiable parent hashes.

NIST SP 800-88 Crypto-Shred

De-provisioning memory buffers are zeroed (`Buffer.fill(0)`) and data volume keys shredded, meeting Tier-1 fintech compliance and media sanitization rules.

Four-Eyes Dual Control (Maker-Checker)

In strict banking profile mode, destructive container tear-downs require a secondary authorized reviewer before volume deletion is executed.

Common Questions

Frequently Asked Questions

How does PortGrid avoid port collisions automatically? >

When you deploy a blueprint, PortGrid verifies socket availability at the kernel level via standard TCP loopback handshake. If the default port (e.g. 5432) is occupied by a native PostgreSQL instance or colleague container, PortGrid deterministically increments the port (e.g. 5433), updates all dependent companion web UIs, and returns updated connection URIs.

Does PortGrid send any data to external cloud servers? >

No. PortGrid is 100% self-hosted and air-gapped ready. All containers bind strictly to 127.0.0.1. PortGrid has zero external telemetry, zero phoning home, and requires no cloud subscriptions.

Can I onboard custom Docker images or private registries? >

Yes. The built-in Service Catalog features an "Onboard Custom Service" workflow designer. You can specify any Docker image from Docker Hub, Quay.io, GitHub Container Registry (ghcr.io), or private enterprise registries, define environment variables, persistent mounts, and optional web UIs.

Is PortGrid suitable for commercial, banking, or defense projects? >

Yes. PortGrid was engineered specifically to pass strict fintech cybersecurity baselines. It implements strict 127.0.0.1 loopback enclaves, FIPS 140-2 AES-256 entropy keys, NIST SP 800-88 cryptographic shredding, and optional Four-Eyes dual control for container teardowns.

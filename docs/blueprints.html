PORTGRID SERVICE BLUEPRINTS

Service Blueprints & Code Snippets

Each PortGrid blueprint pairs an enterprise-grade backend service with an authenticated companion management UI, pre-tuned memory limits, and automated volume persistence.

BLUEPRINT ID: postgres-pgadmin

PostgreSQL 16 + pgAdmin 4 + pgvector

Port 5432 UI Port 5050

Full ACID relational database pre-loaded with the pgvector extension for LLM vector embeddings. The companion pgAdmin 4 console automatically binds with saved connection profiles.

NODE.JS / TYPESCRIPT (PG POOL)
import { Pool } from 'pg';

const pool = new Pool({
  host: 'localhost',
  port: 5432,
  user: 'portgrid',
  password: 'vault_derived_secret',
  database: 'portgrid_app',
  max: 20,
});
SPRING BOOT (APPLICATION.YML)
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/portgrid_app
    username: portgrid
    password: ${PORTGRID_POSTGRES_PASS}
    driver-class-name: org.postgresql.Driver
CLI Deploy: portgrid deploy postgres-pgadmin --with-ui
BLUEPRINT ID: redis-stack-insight

Redis 7.2 Stack + Redis Insight

Port 6379 UI Port 8081

In-memory cache and real-time streaming engine with JSON, Search, TimeSeries, and Probabilistic modules. Redis Insight provides a visual key browser and live stream telemetry.

PYTHON (REDIS-PY)
import redis

r = redis.Redis(
    host='localhost',
    port=6379,
    decode_responses=True
)
r.set('session:token', 'active', ex=3600)
GO (GO-REDIS/V9)
import "github.com/redis/go-redis/v9"

rdb := redis.NewClient(&redis.Options{
    Addr:     "localhost:6379",
    Password: "",
    DB:       0,
})
CLI Deploy: portgrid deploy redis-stack-insight --with-ui
BLUEPRINT ID: kafka-kraft-akhq

Apache Kafka 3.7 (KRaft) + AKHQ Console

Port 9092 UI Port 8080

High-throughput event streaming architecture running modern KRaft consensus without ZooKeeper dependencies. AKHQ console displays consumer group lag, topic schemas, and live message tails.

NODE.JS (KAFKAJS)
const { Kafka } = require('kafkajs');

const kafka = new Kafka({
  clientId: 'order-service',
  brokers: ['localhost:9092']
});
const producer = kafka.producer();
SPRING BOOT (APPLICATION.YML)
spring:
  kafka:
    bootstrap-servers: localhost:9092
    consumer:
      group-id: analytics-consumer
      auto-offset-reset: earliest
CLI Deploy: portgrid deploy kafka-kraft-akhq --with-ui

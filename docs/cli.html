PORTGRID COMMAND LINE INTERFACE

CLI Command Reference

The portgrid command line utility provides complete programmatic control over your local cloud environment, services, cryptographic secret vault, and audit verification.

$ portgrid up

PRIMARY LIFECYCLE

Boots the background orchestrator daemon, binds the bridge network, initializes the FIPS secret vault, and opens the Web Management Console at http://localhost:3000.

portgrid up [--daemon] [--ui-port <p>] [--api-port <p>] [--vault-key <path>] [--offline]
Supported Flags:
  • --daemon, -d : Run orchestrator in background without keeping shell process open.
  • --ui-port <number> : Override default Web Console port (default: 3000).
  • --api-port <number> : Override daemon API port (default: 4000).
  • --offline : Disallow any internet pulls; enforce strictly cached or air-gapped images.

$ portgrid down

TEARDOWN

Gracefully terminates all active blueprint containers, frees ephemeral network ports, and saves current configuration state. Data volumes are preserved by default.

portgrid down [--purge] [--dry-run] [--force]
Supported Flags:
  • --purge : Permanently crypto-shred named data volumes and wipe container state.
  • --dry-run : Simulate teardown steps and display which containers and volumes would be affected.
  • --force : Terminate containers immediately without waiting for graceful SIGTERM timeout.

$ portgrid ps

STATUS & TELEMETRY

Lists all provisioned services, container states, allocated host ports, companion web interfaces, and runtime memory consumption.

portgrid ps [--json] [--watch]

$ portgrid deploy <service-id>

PROVISIONING

Instantiates a specific blueprint from the service catalog. Performs automated port collision avoidance and mounts companion management UIs.

portgrid deploy postgres-pgadmin --with-ui

$ portgrid audit verify

CRYPTOGRAPHIC PROOF

Validates the complete SHA-256 Merkle chain from genesis block to current head. Reports any detected log tampering or parent hash corruption.

portgrid audit verify [--chain] [--export-json <output.json>]

$ portgrid doctor

DIAGNOSTICS

Performs comprehensive health checks across Docker socket connectivity, permissions, port availability, and network bridge health.

portgrid doctor

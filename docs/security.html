FINTECH-GRADE SECURITY ARCHITECTURE

Security, Cryptography & Governance

In regulated environments (banking, healthcare, defence, fintech), local environments are frequent vectors for data exfiltration and unverified state mutations. PortGrid enforces mathematical proof and dual-control governance at every layer.

1 Cryptographic Merkle Tree Audit Ledger

Every lifecycle mutation (service spawn, configuration mutation, volume mount, teardown) generates a structured event block. This block contains the action timestamp, invoking user identity, machine hardware fingerprint, and the cryptographic parent hash:

LEDGER BLOCK STRUCTURE (JSON-CANONICAL) 
{
  "index": 142,
  "timestamp": "2026-10-12T11:45:00.000Z",
  "action": "SERVICE_DEPLOYED",
  "service_id": "postgres-pgadmin",
  "allocated_ports": [5432, 5050],
  "author": "suman.manna@enterprise.corp",
  "parent_hash": "a1b2c3d4e5f67890123456789abcdef0123456789abcdef0123456789abcdef0",
  "state_hash": "e93a74b1c85309d9f123456789abcdef0123456789abcdef0123456789abcdef",
  "merkle_root": "7b8a9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b"
}

If any local log file is modified, truncated, or tampered with, parent hash recalculation immediately detects the mismatch and locks down orchestrator operations.

2 Four-Eyes Maker-Checker Policy

Accidental database drops and volume purges cost organizations countless hours of engineering downtime. PortGrid includes an optional Four-Eyes approval mode:

MAKER (INITIATOR)

Developer requests high-risk operation: volume purge, production replication pull, or credential rotation. The request is placed in pending approval holding.

CHECKER (APPROVER)

Team lead or peer enters cryptographically signed approval key to execute the queued task. Both identities are sealed permanently in the Merkle ledger.

3 FIPS 140-2 Encrypted Secret Enclave

Passwords, TLS certificates, and connection URIs are never written in plain text to Docker environment variables or local disk configuration files:

  • [OK] AES-256-GCM authenticated symmetric encryption with 96-bit initialization vectors
  • [OK] PBKDF2 key derivation using 600,000 HMAC-SHA512 iterations
  • [OK] Ephemeral in-memory injection directly into container runtime namespaces

4 NIST SP 800-88 Cryptographic Shredding

When a developer executes portgrid down --purge, PortGrid executes a cryptographic zeroing routine. The ephemeral encryption key protecting the storage volume is overwritten with random entropy before the volume unmount call completes, making deleted databases mathematically unrecoverable.

5 Isolated Network Enclaves

Services run inside a dedicated user-defined Docker bridge network (portgrid-network). Inter-container communication occurs via internal DNS aliases without exposing unneeded ports to external network interfaces (0.0.0.0). All host bindings are strictly bound to 127.0.0.1 by default.
